# Informe protegido

Página estática con un informe de campañas de recobro. El contenido está **cifrado con AES-256**
y se descifra en el navegador al introducir la contraseña. No hay servidor ni backend: GitHub Pages
solo entrega el fichero cifrado.

- `index.html` — página de acceso + carga cifrada.
- El contenido original no está en este repositorio, solo su versión cifrada.

Sin la contraseña, el fichero descargado no se puede leer ni inspeccionando el código fuente.
Si necesitas el informe en otro formato, pídelo a Weaves.
